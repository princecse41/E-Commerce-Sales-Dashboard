# E-Commerce-Sales-Dashboard

# 🛒 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard** built using **Microsoft Power BI**. The dashboard analyzes sales performance, customer behavior, product performance, and profit analysis to help businesses make data-driven decisions.

The dashboard provides an easy way to monitor important business metrics through interactive visualizations and KPIs.

## 🎯 Objectives

- Analyze overall sales performance.
- Identify top-selling products.
- Monitor profit and revenue.
- Understand customer purchasing behavior.
- Compare payment methods.
- Analyze order priorities.
- Track daily sales trends.

## 📊 Dashboard Pages

### 1️⃣ Dashboard Overview

Provides an overall summary of business performance.

KPIs Included:

- Total Sales
- Total Amount
- Total Profit
- Total Customers

Visualizations:

- Daily Sales Trend
- Sales by Order Priority
- Sales by Payment Method
- Sales by Product
- Sales by Gender

---

### 2️⃣ Product Analysis

Includes:

- Top Selling Products
- Product Category Analysis
- Product Profit Analysis
- Product Sales Comparison

---

### 3️⃣ Customer Analysis

Includes:

- Customer Distribution
- Gender-wise Sales
- Customer Login Type
- Payment Method Preference

---

### 4️⃣ Profit & Cost Analysis

Includes:

- Total Profit
- Cost Analysis
- Profit Margin
- Sales vs Profit
- Shipping Cost Analysis
